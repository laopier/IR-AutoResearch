# SA0 小规模任务书（2026-10-01）

用户希望在学习科研工程能力的过程中推进学长方案，并已同意开始 SA0。
本次由当前对话中的一个 Codex agent 提出并执行一个候选，不调用额外 agent 或 LLM API。
这是人类监督的工程演练，不算学长方案要求的独立 AutoResearch 正式运行。

目标：走通冻结起点 → 同预算 baseline → 提前登记假设 → 修改 → 训练 → 独立进程评估 → 保留/回退。

- 起点：当前项目的 MAVI 和训练实现，复制到独立 Git 仓库。原项目 train 文件不修改。
- 可改：副本的 `train/mavi.py`、`train/experiment.py`；其余源码和数据按 SHA256 校验。
- 预算：baseline 和一个候选，各 5 步、batch size 1、seed 0；学习率周期固定 200000 步。
- 使用原 smoke 清单的 3 个训练样本、1 个验证样本；不使用剩余样本作隐藏测试。
- 训练和验证分开启动，训练 worker 的 Python 文件访问白名单不包含验证数据目录。
- 两次试验总进程墙钟预算 240 秒，单试验 120 秒，失败也计次数和耗时。
- 保留规则仅用于演示：MAE 严格下降，NRMS 不升，SSIM 不降，参数和训练峰值显存不超过 baseline 的 1.1 倍。
- 每次保存代码 commit、diff、数据/代码哈希、假设、逐步训练记录、指标、checkpoint、资源账本。
- 本轮不浏览网络获取候选策略。桌面 agent 的 token 和 API 成本无法从本工具读取，记录为未知，不能填零。

限制：Python audit 和源码校验是工程护栏，不是操作系统级安全隔离。当前对话的 agent 仍有宿主机权限；
不得宣称已实现可信的隐藏测试、防恶意代码沙箱或全自动搜索平台。正式 SA0 需要完整数据、正式 B0、
按设计隔离的数据划分、独立研究轮次与可核算的搜索预算。

学习顺序：先看 control.py 的 init，再看 propose/commit/run，最后看 worker.py 和 decide。
