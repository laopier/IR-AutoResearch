# N28 128训练32验证数据抽取

工具：prepare/pilot_stream.py。抽样与模型结果无关，固定seed=0。
从官方train_N28.csv中选四个RTL变体，每个32训练、8开发验证；不使用官方test_N28.csv中的样本。
布局分组使用设计变体、宏数量、时钟、利用率、宏摆放；同组的power mesh/filler变体不能跨划分。
每组只选一个样本，并优先覆盖主要实现条件。mNone在官方清单中存在，保留为明确类别。
这是已有设计族内的开发划分，不是未知RTL或严格设计泛化评测。

实际输出目录：D:/Project/datasets/IRDrop_N28_pilot_160（不进入Git）。
SELECTION.json和train.csv/validation.csv先生成，并不表示数据已完成。
只有DATASET.json中ready=true及PROGRESS.json中phase=completed才可训练。

```bash
python -u -m prepare.pilot_stream \
  --source /mnt/d/WSL/Project/CircuitNet-main/routability_ir_drop_prediction/files/train_N28.csv \
  --official-test /mnt/d/WSL/Project/CircuitNet-main/routability_ir_drop_prediction/files/test_N28.csv \
  --output /mnt/d/Project/datasets/IRDrop_N28_pilot_160 --seed 0
```

Google Drive官方目录：
https://drive.google.com/drive/folders/18DzI3RRYDF0T5VlMwmkYdFx0kVuW3sql
下载/解压规范：https://circuitnet.github.io/intro/download.html
命名及实现条件：https://circuitnet.github.io/feature/properties.html
预处理基准：https://github.com/circuitnet/CircuitNet/blob/main/routability_ir_drop_prediction/preprocess_scripts/generate_training_set.py

流式读取5个静态特征/标签包和power_t的11个分卷，分卷不拼接成第二份大文件，不全量解压。
只保存160个样本的6种原始数组；官方原始成员可能无.npy扩展名，内容不变，只统一本地扩展名。
兼容官方部分包的双层gzip。Range缓存保留已读前缀，重启可复用，未完成成员以.partial标记。
网络错误会有限重试，HTML错误页、偏移和总大小不一致会拒绝作为数据。
解压仅把已选样本的内容写入受控路径，不使用extractall，不执行归档代码。
压缩数据最坏约29GiB，此外还需原始子集和处理数据空间；低于3GiB余量时暂停，缓存保留。

提取完成后按官方顺序生成4静态+20时间通道、256×256，逐通道min-max。
标签先裁剪[1e-6,50]、INTER_AREA重采样，再用(log10(D)+6)/(log10(50)+6)变换。
非零常量特征可能触发官方min-max除零，本工具明确失败，不静默改变配方。
记录原始数组与处理数组hash、shape/dtype/范围、清单hash、预处理器hash。
标签为对数归一化尺度，不能直接称mV；原始物理单位仍须来源确认。
